# Houston Mobile Mechanic & Diesel Repair LLC

Professional mobile auto and diesel repair website - bringing the shop to your location, 24/7 across Houston and surrounding areas.

## 🚗 About

This is a professional, modern website for a mobile mechanic service in Houston, TX. The site emphasizes convenience, 24/7 availability, and comprehensive automotive repair services performed at the customer's location.

## ✨ Features

- **Fully Responsive Design** - Optimized for mobile, tablet, and desktop
- **Modern Dark Theme** - Automotive-focused design with signature orange/red accent
- **SEO Optimized** - Complete meta tags, structured data, and semantic HTML
- **Performance Optimized** - WebP images, lazy loading, efficient CSS/JS
- **Accessibility Compliant** - ARIA labels, keyboard navigation, skip links
- **Interactive Components**:
  - Mobile navigation menu
  - FAQ accordion
  - Quote request form with validation
  - Interactive service area map
  - Scroll reveal animations
  - Sticky header

## 🚀 Quick Start

1. **Clone or download** this repository
2. **Open `index.html`** in a web browser
3. Or serve with any static web server:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (with http-server)
   npx http-server
   ```

## 🔧 Customization

Before deploying to production, update these items:

### Required Changes
1. **Domain URLs**: Replace `houstonmobilemechanic.example` with your actual domain throughout all HTML files
2. **Google Business Profile**: Add your real Google review link in `script.js`
3. **Form Backend**: Connect the quote form to your email service or CRM

### Optional Enhancements
- Add Google Analytics tracking code
- Connect contact form to backend (PHP, Node.js, or form service like Formspree)
- Replace placeholder testimonials with real customer reviews
- Add Google Maps integration for service area
