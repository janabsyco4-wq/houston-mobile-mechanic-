# Houston Mobile Mechanic & Diesel Repair LLC

A professional, mobile-first website for a Houston-based mobile mechanic and diesel repair service.

## 🚗 Features

- **24/7 Mobile Service** - Fully responsive design emphasizing emergency availability
- **Professional Design** - Dark automotive theme with signature red-orange gradient
- **SEO Optimized** - Complete meta tags, structured data, and semantic HTML
- **Interactive Elements** - Quote forms, FAQ accordion, service area map
- **Accessibility Compliant** - ARIA labels, keyboard navigation, skip links
- **Performance Optimized** - WebP images, lazy loading, smooth animations

## 🚀 Getting Started

1. Clone this repository
2. Open `index.html` in a web browser
3. Or serve with any local server:
   ```bash
   # Python
   python -m http.server 8000
   
   # Node.js
   npx http-server
   
   # PHP
   php -S localhost:8000
   ```

## 📝 Before Going Live

Update these items in the HTML files:

1. **Domain URLs**: Replace `houstonmobilemechanic.example` with your actual domain
2. **Google Reviews Link**: Add real Google Business Profile URL in `script.js`
3. **Form Backend**: Connect contact form to email service or backend API
4. **Analytics**: Add Google Analytics or tracking code if needed
5. **Testimonials**: Replace placeholder reviews with actual customer testimonials
